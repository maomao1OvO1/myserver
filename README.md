# 🏆 myserver · 小游戏排行榜服务器

一个**纯 Node.js（零第三方依赖）**的小型排行榜后端，给网站上的小游戏记分用：
游戏结束 → 上报分数 → 每款游戏各自维护一份全球榜单 → 打开 `/ranking` 就能看。

## 功能
- **统一接口**：所有小游戏共用一套上报 / 查询接口，每款游戏一份独立榜单
- **防刷分**：同一玩家短时间只允许提交一次（限流）+ 分数上限（越界判异常）+ 玩家名清洗
- **方向可配**：`best=min` 表示越小越好（比如「猜数字」比的是次数），`best=max` 表示越大越好
- **零依赖**：只用 Node 内置的 `http` / `fs`，不依赖 Express，扔哪都能跑

## 跑起来
```bash
node server.js             # 默认 3000 端口
PORT=8080 node server.js   # 换端口
```

## 文件
| 文件 | 作用 |
|---|---|
| `server.js` | 服务器本体（路由 + 榜单读写 + 防刷分） |
| `ranking.html` | 榜单展示页 |
| `test.html` | 上报测试页 |
| `scores.json` | 榜单数据（本地文件存储；已在 `.gitignore` 里，不进仓库） |

## 说明
- 数据用**文件存储**（`scores.json`），适合小流量；人数多了建议换成数据库
- 这是早期版本；现在主站上的排行榜主力是 **Firestore**（见主站仓库）
